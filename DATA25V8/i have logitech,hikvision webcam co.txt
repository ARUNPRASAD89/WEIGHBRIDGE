Excellent question. You are describing a classic, real-world automation scenario for a weighbridge.

Yes, this is absolutely possible and is a highly effective way to automate your system. Triggering image capture based on the weight reading is the most efficient method. It ensures you only run the license plate recognition (LPR) when a vehicle is actually on the scale.

Here is a complete breakdown of how to build this system, integrating the weight data with your Logitech and Hikvision webcams.

The System Workflow
This is how the process will work from start to finish:

Monitoring the Weight: A Python script will continuously read the data from your weighing scale's indicator.
The Trigger Condition: The script will wait for the weight to cross a threshold (e.g., > 200 kg). This indicates a vehicle has mounted the scale.
Image Capture: As soon as the weight is triggered, the script will instantly capture images from both your Logitech and Hikvision webcams.
LPR Processing: The script will then run your license plate recognition function on the captured images. Using two cameras increases the chance of getting a clear shot.
Data Logging: The final license plate number, weight, date, and time are saved to your database or a log file.
Reset: The script then waits for the weight to drop below a certain value (e.g., < 100 kg), which signifies the vehicle has left, and the system is ready for the next one.
Step 1: Getting the Weight Data from the Indicator (The Most Important Part)
This is the most critical step. Your weighing indicator needs to send the weight data to your computer. Most industrial indicators have a Serial Port (RS-232) for this purpose.

Check the Indicator: Look at the back of your weighing indicator for a 9-pin or 25-pin serial port (often labeled RS-232 or COM).
Connect to PC: You will need a USB to RS-232 Serial Adapter Cable. This is a standard and inexpensive cable that connects the indicator's serial port to a USB port on your computer.
Install the Python Library: To read from this serial port, you need the pyserial library.

The indicator will continuously send out the weight as a stream of text (e.g., ST,GS,+00350.0kg\r\n). Your Python code will listen to this stream, parse the text to get the number, and use it as the trigger.

Step 2: Accessing Your Logitech and Hikvision Webcams
Since both are USB webcams connected to your computer, OpenCV can access them easily. The only challenge is identifying which camera is which.

When you have multiple cameras, OpenCV assigns them an index number starting from 0. For example, 0 might be the Logitech, and 1 might be the Hikvision. You may need to experiment to find the correct index for each.

Step 3: The Integrated Python Script
Here is a complete, commented Python script that ties everything together. This script monitors the weight, triggers the cameras, and prepares for LPR.

Before you run this, you need to:

Find the correct COM port for your USB-to-Serial adapter (e.g., COM3 on Windows, /dev/ttyUSB0 on Linux). You can find this in the Device Manager on Windows.
Find the correct camera indices for your Logitech and Hikvision webcams.
Python
import cv2
import serial
import time
import re
from datetime import datetime

# --- Configuration ---
# Serial Port settings for the weighing indicator
SERIAL_PORT = 'COM3'  # <-- IMPORTANT: Change this to your actual COM port
BAUD_RATE = 9600

# Camera settings
# You might need to swap these numbers if your cameras are indexed differently.
LOGITECH_CAM_INDEX = 0
HIKVISION_CAM_INDEX = 1

# Trigger settings
WEIGHT_THRESHOLD_KG = 200
VEHICLE_ON_SCALE = False # State flag to track if a vehicle is present

def parse_weight(serial_data_string):
    """
    Parses the raw string from the indicator to get the weight in kg.
    This function needs to be customized based on your indicator's output format.
    Example format: 'ST,GS,+00350.0kg'
    """
    try:
        # Use regular expressions to find a number (integer or float)
        match = re.search(r'([0-9]+\.?[0-9]*)', serial_data_string)
        if match:
            return float(match.group(1))
    except Exception as e:
        print(f"Could not parse weight from '{serial_data_string}': {e}")
    return 0.0

def run_lpr_on_image(image, camera_name):
    """
    Placeholder for your actual license plate recognition function.
    """
    print(f"Running LPR on image from {camera_name}...")
    # In a real system, you would call your EasyOCR or YOLO+OCR function here.
    # For now, we'll just save the image.
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"capture_{camera_name}_{timestamp}.jpg"
    cv2.imwrite(filename, image)
    print(f"Saved image to {filename}")
    # return "YOUR_LPNR_RESULT"

# --- Main Program ---
try:
    # Initialize connection to the weighing scale
    scale_serial = serial.Serial(SERIAL_PORT, BAUD_RATE, timeout=1)
    print(f"Successfully connected to weighing scale on {SERIAL_PORT}")
except serial.SerialException as e:
    print(f"Error: Could not connect to weighing scale on {SERIAL_PORT}. {e}")
    print("Please check the port name and ensure the device is connected.")
    exit()

# Initialize camera connections
cam_logitech = cv2.VideoCapture(LOGITECH_CAM_INDEX)
cam_hikvision = cv2.VideoCapture(HIKVISION_CAM_INDEX)

if not cam_logitech.isOpened() or not cam_hikvision.isOpened():
    print("Error: Could not open one or both webcams. Check indices.")
    exit()

print("System is running. Waiting for vehicle...")
print("-" * 30)

try:
    while True:
        # Read data from the serial port
        serial_line = scale_serial.readline().decode('utf-8').strip()
        
        if serial_line:
            current_weight = parse_weight(serial_line)
            print(f"Current Weight: {current_weight:.2f} kg", end='\r')

            # --- TRIGGER LOGIC ---
            # A vehicle has just arrived
            if current_weight > WEIGHT_THRESHOLD_KG and not VEHICLE_ON_SCALE:
                print("\n--- VEHICLE DETECTED! ---")
                VEHICLE_ON_SCALE = True # Set the flag so we don't re-trigger
                
                print("Capturing images...")
                # Capture a frame from each camera
                ret_logi, frame_logi = cam_logitech.read()
                ret_hik, frame_hik = cam_hikvision.read()
                
                if ret_logi and ret_hik:
                    # Process both images for LPR
                    run_lpr_on_image(frame_logi, "Logitech")
                    run_lpr_on_image(frame_hik, "Hikvision")
                    
                    # Log the event
                    print(f"Event logged at {datetime.now().strftime('%Y-%m-%d %H:%M:%S')} with weight {current_weight:.2f} kg")
                else:
                    print("Error: Failed to capture from one or both cameras.")
                
                print("-" * 30)
                print("System is running. Waiting for vehicle to leave...")

            # A vehicle has just left
            elif current_weight < WEIGHT_THRESHOLD_KG and VEHICLE_ON_SCALE:
                print("\n--- Vehicle has left the scale. System reset. ---")
                VEHICLE_ON_SCALE = False # Reset the flag
                print("System is running. Waiting for vehicle...")
                print("-" * 30)

        time.sleep(0.1) # Small delay to prevent high CPU usage

except KeyboardInterrupt:
    print("\nProgram stopped by user.")
finally:
    # Clean up all connections
    scale_serial.close()
    cam_logitech.release()
    cam_hikvision.release()
    cv2.destroyAllWindows()
    print("All resources released.")
